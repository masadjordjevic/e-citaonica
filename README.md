# E-Čitaonica 

E-Čitaonica je web aplikacija za zajedničko učenje razvijena pomoću Next.js i Supabase platforme.

## Funkcionalnosti

Praćenje aktivnosti članova
Tajmer za učenje
Grupni chat
Zajedničke beleške
Virtuelna bašta
Virtuelni kafić
Digital Diary
Daily Question
Obaveštenja u realnom vremenu

## Tehnologije

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase

## Pokretanje projekta

```bash
npm install
npm run dev
```

Aplikacija će biti dostupna na:

```
http://localhost:3000
```
